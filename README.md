# 📈  Investment Firm Dashboard 

## Info-Data

This dashboard follows up on my data analytics project for as investment firm (You can find the full project [here](https://github.com/theodorosmalezidis/Investment_Firm_Analytics/tree/main)).  This visualized report includes 2 dashboards. The first contains key performance indicators with year-over-year (YoY) changes, tracks quarterly trends in Net Flows and Fee Revenues and highlights cumulative client retention rates. The second provides a detailed list of all branch performance across key metrics, comparing current yearly results against the Prior Year (PY) to track localized growth.


## Key Takeaways

**1. The "Retention vs. Revenue" Paradox**

- The firm maintains a High Cumulative Retention Rate, proving that the core asset base is loyal and the firm is not "leaking" clients.
- Between 2023 and 2024, there was a minor but consistent downward trend in Transaction Volume and Net Flows  which leads to Fee Revenues  decrease also.

**The Insight:** The firm is successfully keeping its clients, but those clients are becoming less active. This suggests a shift from "Active Trading" to a "Buy and Hold" mentality, or a decrease in new investable capital.

**2.  More Clients ≠ More Value**

- Active Client Counts rose year-over-year, yet total new capital flows or/and transaction frequency declined.

- Managing more clients with lower revenue per head increases operational overhead without a corresponding increase in the bottom line.

**Forward-Looking Recommendations:**

-Implement upselling strategies to increase the Net Flow per Client.
-Advisors should promote diversified product solutions. This has a two-fold benefit : a) fortifies portfolio's stability for the client b) enhances the firm’s fee-based income.
-Establish a new Recurring Revenue Model through Assets Under Management (AUM) fees, that will create a more predictable revenue stream for the firm.
